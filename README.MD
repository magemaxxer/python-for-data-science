MAGE
PYTHON FOR DATA SCIENCE

A Structured Learning Curriculum

Learning pathway: Beginner → Python Programmer → Data Analyst → Data Scientist → Computational Sociologist

Primary language: Python

Learning environment: VS Code and Jupyter Notebook

Approach: Theory + coding exercises + mini-projects + practical research

CURRICULUM OBJECTIVES

By the end of this curriculum, you should be able to:

Write Python programs independently.
Understand programming logic, syntax and fundamental concepts.
Work with different data structures and manipulate information.
Collect, clean and process datasets.
Use Python libraries for numerical computing and data analysis.
Conduct exploratory data analysis (EDA).
Apply statistical methods to investigate relationships and patterns.
Create meaningful data visualisations.
Retrieve and work with data through APIs.
Conduct independent data-driven research.
Understand the foundations of machine learning and natural language processing.
Apply computational methods to investigate social and cultural phenomena.
