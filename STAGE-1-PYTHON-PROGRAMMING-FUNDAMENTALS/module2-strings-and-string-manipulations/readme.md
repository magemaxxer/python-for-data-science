Lesson 1.2: Data Types

Learn:
Integers (int).
Floating-point numbers (float).
Strings (str).
Booleans (bool).
None.
Checking data types using type().
Type conversion.

Exercises:
Create one variable for each fundamental data type.

Convert a string containing a number into an integer.

Convert an integer into a string.

Investigate what happens when you add different data types.

Create a program that calculates the average of three numerical values.
